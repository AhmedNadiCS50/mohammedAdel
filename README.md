# منصة "مادة التكنولوجيا مع الخبير مستر محمد عادل" التعليمية (دفعة 2027)

منصة تعليمية ويب متكاملة (Full-Stack) مخصصة لمستر **محمد عادل** لتدريس مادة التكنولوجيا والبرمجة لطلاب المرحلة الثانوية (علمي وأدبي)، جاهزة للعمل والاستخدام الفعلي مع الطلاب End-to-End.

---

## 🌟 مميزات المنصة

1. **الهوية والتصميم الرسمي:**
   - العنوان الرئيسي المعتمد في الهيدر والمتصفح: **"مادة التكنولوجيا مع الخبير مستر محمد عادل"**.
   - دمج الصورة الأصلية لمستر محمد عادل في الهيدر وقسم "تعرف على الخبير" بالصفحة الرئيسية.
   - هوية بصرية أنيقة: أخضر داكن رسمي (`Emerald Green`) مع الأبيض والذهبي المتناسق مع شعار دفعة 2027، وخط عربي حديث (`Cairo`) متجاوب بالكامل للهواتف (Mobile-First RTL).

2. **قسم المنتجات والكتب الورقية (`/products`):**
   - صفحة عامة متاحة لجميع الزوار بدون الحاجة لتسجيل دخول.
   - عرض غلاف وتفاصيل **"كتاب الصف الثاني البكالوريا برمجة"** تأليف مستر محمد عادل.
   - السعر: **"قريبًا"** (كما طلبتم، لحين تحديده).
   - زر مباشر **"اطلب نسختك الآن عبر واتساب"** يفتح شات واتساب برقم المستر ورسالة حجز جاهزة بدون أي بوابات دفع معقدة.

3. **لوحة تحكم المدرس وسجل الطلاب (Owner Profile):**
   - الدخول: اسم المستخدم `admin`، كلمة المرور `adel2027`.
   - **سجل الطلاب (`/admin/students`):** قائمة بجميع الطلاب، والضغط على أي طالب يفتح صفحته الفردية.
   - **تفعيل اشتراك الشهر يدوياً:** تفعيل شهر كامل بضغطة زر بعد استلام تحويل فودافون كاش أو إنستاباي.
   - **إتاحة وصول جزئي:** إمكانية فتح أو قفل درس/كورس معين للطالب دون تفعيل باقي الشهر.
   - **سجل عمليات التفعيل (Logs):** سجل تاريخي بكل التفعيلات اليدوية وتفعيل الأكواد بتوقيتها الدقيق.
   - **توليد أكواد التفعيل (`/admin/codes`):** توليد أكواد عشوائية مؤمنة مع زر نسخ الكود ورسالة واتساب بضغطة واحدة.
   - **تنبيهات انتهاء الاشتراك:** قسم يوضح الطلاب الذين تنتهي اشتراكاتهم خلال 2-3 أيام مع زر تذكير مباشر على واتساب.

4. **إدارة المحتوى وحماية الفيديوهات:**
   - رفع وإدارة المحاضرات بروابط يوتيوب غير المدرجة (`Unlisted`).
   - مشغل فيديو محمي مدمج يمنع ظهور روابط الفيديو المباشرة.
   - **علامة مائية أمنية ذكية (Anti-Piracy Watermark):** تتحرك تلقائياً على شاشة الفيديو باسم الطالب ورقم هاتفه لمنع تصوير الشاشة وتسريب الشرح.
   - إتاحة الدروس والامتحانات حصرياً للطلاب أصحاب الاشتراكات النشطة أو الكورسات المفتوحة لهم.

5. **الامتحانات الإلكترونية والتصحيح التلقائي:**
   - بنك أسئلة واختبارات اختيار من متعدد (MCQ) مع مؤقت زمني ونسبة نجاح.
   - تصحيح تلقائي فوري وعرض النتيجة ونسبة النجاح واحتفال Confetti.
   - مراجعة تفصيلية للإجابات الصحيحة والخاطئة مع توضيحات المستر النموذجية.

6. **لا بيانات وهمية (Zero Dummy Data):**
   - تم تسليم المنصة نظيفة تماماً بدون أي طلاب تجريبيين أو نتائج وهمية أو إحصائيات مصطنعة.

7. **منتدى الأسئلة والنقاش المباشر (`/forum`):**
   - منتدى خاص بكل صف دراسي، يجمع أسئلة ونقاشات طلاب الدفعة في مكان واحد.
   - **مباشر (Realtime):** أي سؤال أو رد يتم تحديثه فوراً بدون إعادة تحميل الصفحة (Firestore `onSnapshot`).
   - **مراجعة قبل النشر:** سؤال الطالب يدخل حالة "قيد المراجعة" ولا يظهر في المنتدى إلا بعد موافقة المدرس من لوحة التحكم.
   - **لوحة مراجعة المدرس (`/admin/forum`):** قبول / رفض (مع سبب يصل للطالب) / تثبيت / حذف، مع عدّاد مباشر للأسئلة والردود المعلقة في الشريط العلوي.
   - **ردود مباشرة:** رد المدرس يُنشر فوراً ويظهر بعلامة "إجابة المدرس"؛ ردود الطلاب تخضع للمراجعة أيضاً.
   - وصول المنتدى مخصص للطلاب الذي فُعّلت اشتراكاتهم (المفعلين).
   - بحث فوري في الأسئلة والأجوبة، وتبويب "أسئلتي" لمتابعة حالة أسئلة الطالب.

## ☁️ ربط Firebase (الباقة المجانية 100%)

المنصة تعمل حالياً بوضع التخزين المستمر فائق الأداء، وإذا أردت ربطها بـ Firebase Firestore مجاناً طوال العام:
1. توجه إلى [Firebase Console](https://console.firebase.google.com).
2. أنشئ مشروعاً جديداً باسم `MrMohamedAdel-Platform`.
3. فعّل **Firestore Database** و **Authentication**.
4. انسخ مفاتيح الـ Config وضعها في ملف `.env.local`:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

### 🔧 تفعيل المنتدى المباشر (Firestore Realtime) — خطوات للمدرس

منتجى الأسئلة يحتاج Firestore شغّال (المفتاح أعلاه كافٍ). عند أول تشغيل سيطلب Firebase إنشاء **الفهرس المركّب** تلقائياً من خلال رابط في رسالة الخطأ في المتصفح:
- الفهرس المطلوب لمجموعة `forum_posts` على (حقل `grade` تصاعدي + حقل `status` تصاعدي). اضغط الرابط في رسالة الخطأ وأكّد الإنشاء، ثم حدّث الصفحة.

يُنصح أيضاً بنشر قواعد الأمان الموجودة في ملف `firestore.rules` (بأمر `firebase deploy --only firestore:rules`) حتى لا يستطيع أحد النشر في المنتدى بلا إذن أو تغيير حالات المنشورات.
